# ROYALTIM-3

Топ-даун 3D батл-рояль на Godot 4.7 про овощи и фрукты. Остров из шестиугольных тайлов генерируется заново каждый матч, а вместо классической зоны край острова загорается и превращается в горы, сжимая поле боя к центру.

## Скачать

Готовая сборка для Windows лежит в разделе [Releases](https://github.com/whaleopop/Tomato/releases): распакуйте `Royaltim-windows.zip` и запустите `Royaltim.exe`.

## Что есть в игре

- **13 героев** со своими характеристиками, активной и пассивной способностью.
- **12 видов оружия**: пистолеты, дробовики, снайперки, миниган, огнемёт, гранатомёт и другие, у каждого свой режим стрельбы.
- **Процедурный остров**: террасы на трёх уровнях с обрывами и пандусами, озёра, реки и водопады, тропинки, хижины. С высоты видно дальше, на уступ можно запрыгнуть, из воды под обрывом можно подтянуться.
- **Особые биомы**: цветочный луг лечит, на инее быстро, но скользко, высокая трава прячет, в грибной роще способности заряжаются быстрее, но хуже видно, шиповник ранит.
- **Ориентиры с лутом**: старая мельница, теплица, гигантская лейка, холм пугала, компостная куча. Там стоит большая часть сундуков, в теплице и на мельнице лучший лут. Ориентиры видны на карте высадки и на миникарте.
- **Сжимающаяся зона**: край помечается трещинами, загорается, потом из него вырастают горы и выталкивают игроков к центру. К концу матча день сменяется закатом.
- **События на карте**: метеоритный дождь, землетрясение, ночь и туман, разлив, раскол острова, грядка с бонусом, сброс припасов, сдвиг финального центра.
- **Укрытия и туман войны**: стены, кусты и деревья закрывают обзор и линию огня. Сервер не присылает клиенту игроков, которых тот не должен видеть.
- **Магазин**: герои, скины, шапки и раскраски оружия за монеты из матчей. Покупки видят все игроки.
- **Полигон**: офлайн-площадка со всем оружием, манекенами, мишенями и счётчиком урона. Tab открывает выбор героя.
- **Атмосфера**: трава и цветы на ветру, бабочки, пыльца, светлячки ночью, тени облаков, фоновые звуки природы.
- **Сетевая игра**: авторитетный сервер на ENet, хост может играть сам, есть вход в уже идущий матч.
- **Справочник** в главном меню: герои, оружие, предметы, события и правила с настоящими цифрами из игры.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD или стрелки |
| Стрельба | ЛКМ |
| Прыжок | Пробел |
| Бег | Shift |
| Перезарядка | R |
| Взаимодействие (сундуки, предметы) | X |
| Способности | F, G, H, J |
| Слоты оружия | 1-5 |
| Инвентарь | I |
| Поворот камеры | Q / E (или мышь у края экрана), сброс C |
| Приближение камеры | = / - |
| Пауза | Esc |

## Запуск из исходников

1. Установите Godot 4.7.
2. Откройте папку проекта в редакторе.
3. Запустите сцену `scenes/MainMenuScene.tscn` (она же главная сцена проекта).

Для сетевой игры один игрок выбирает в меню хост, остальные подключаются по IP (по умолчанию 127.0.0.1).

## Сборка и релизы

GitHub Actions (`.github/workflows/build.yml`) собирает Windows-версию при каждом пуше в master, архив лежит в артефактах запуска. Чтобы выпустить релиз, поставьте тег `v*` и запушьте его:

```
git tag -a v0.2.0 -m "Royaltim v0.2.0"
git push origin master --follow-tags
```

Сборка появится в Releases, описанием станет сообщение последнего коммита.

## Структура проекта

```
core/          компоненты (движение, здоровье, бой, способности, инвентарь, статусы), сущности, ресурсы
characters/    данные героев и реестр
abilities/     активные и пассивные способности
combat/        стрельба и попадания
inventory/     предметы и таблицы лута
network/       сервер, клиент, синхронизация
world/
  generation/  генерация острова, террасы, биомы, декор, водопады
  destruction/ сжимающаяся зона
  events/      события на карте
  landmarks/   ориентиры
  cover/       стены, кусты, деревья
  loot/        сундуки и предметы на земле
  visibility/  туман войны
  ambience/    частицы и звуки окружения
ui/            меню, HUD, магазин, профиль игрока, локализация
shaders/       шейдеры земли, воды, растительности, интерфейса
scenes/        игровые сцены, полигон, катсцены
tools/         генерация 3D-моделей по картинкам
dev/trailers/  запись трейлеров
```

Подробное описание архитектуры и правил, которые нельзя нарушать, лежит в `CLAUDE.md` и `ARCHITECTURE.md`.

## Тесты

Тесты написаны на GUT и лежат в `tests_disabled/`. Чтобы их запустить, установите GUT, перенесите тесты в `tests/` и выберите `Project -> Tools -> Run Tests`.
