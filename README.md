# 🥬 ROYALTIM-3: 3D Top-Down Battle Royale

**3D Top-Down Battle Royale игра на Godot 4.5.1 с антропоморфными овощами и фруктами**

## 🎮 Описание

ROYALTIM-3 - это battle royale игра в стиле top-down 3D, где игроки играют за антропоморфные овощи и фрукты. Игра использует процедурную генерацию гексагональной карты и систему разрушения карты вместо классической зоны.

## ✨ Особенности

- **Component-Based Architecture** - модульная система компонентов для легкого расширения
- **Dedicated Server** - серверная авторитетная логика для честной игры
- **Процедурная генерация** - гексагональная карта генерируется процедурно
- **Разрушение карты** - части карты разрушаются со временем, сжимая игровое пространство
- **8 уникальных персонажей** - каждый с активными и пассивными способностями
- **Система способностей** - активные и пассивные способности для каждого персонажа
- **Система лута** - сундуки с оружием, аптечками и перками
- **Синхронизация через ENet** - надежная сетевая синхронизация

## 🏗️ Архитектура проекта

```
/
├── core/                    # Основные системы
│   ├── components/          # Компоненты (Movement, Health, Combat, etc.)
│   ├── entities/            # Сущности (Entity, Player)
│   └── resources/           # Ресурсы (CharacterData, WeaponData, etc.)
├── characters/              # Данные персонажей
│   └── data/               # Файлы персонажей
├── abilities/               # Система способностей
│   ├── active/             # Активные способности
│   └── passive/            # Пассивные способности
├── inventory/               # Система инвентаря и лута
│   ├── items/              # Типы предметов
│   └── loot/               # Генерация лута
├── network/                 # Сетевая система
│   ├── server/             # Серверная логика
│   ├── client/             # Клиентская логика
│   └── sync/               # Синхронизация
├── world/                   # Мир игры
│   ├── generation/         # Генерация карты
│   ├── destruction/        # Разрушение карты
│   └── objects/            # Объекты мира (сундуки, постройки)
├── ui/                      # Интерфейс
│   ├── hud/                # HUD элементы
│   └── menus/              # Меню
├── combat/                  # Боевая система
├── scenes/                  # Игровые сцены
└── tests/                   # Тесты
```

## 🚀 Запуск

### Требования
- Godot 4.5.1 Stable

### Запуск сервера
1. Откройте проект в Godot
2. Запустите сцену `scenes/GameScene.tscn`
3. Нажмите "Start Server" в главном меню

### Подключение клиента
1. Запустите игру
2. Нажмите "Connect to Server"
3. Введите IP адрес сервера (по умолчанию 127.0.0.1)

## 🎯 Управление

- **WASD** - Движение
- **ЛКМ** - Атака
- **1-4** - Использование способностей
- **E** - Взаимодействие (открыть сундук)
- **Tab** - Инвентарь
- **ESC** - Меню паузы

## 🔧 Разработка

### Добавление нового персонажа

1. Создайте файл в `characters/data/` наследуя от `CharacterData`
2. Определите характеристики и способности
3. Добавьте 3D модель в `models/`

### Добавление новой способности

1. Создайте класс наследуя от `ActiveAbility` или `PassiveAbility`
2. Реализуйте методы активации/применения
3. Добавьте способность в данные персонажа

### Добавление нового предмета

1. Создайте класс наследуя от `ItemData`
2. Определите свойства предмета
3. Добавьте в таблицу лута
